# QVM

This repository holds the Quantova post quantum virtual machine. It defines a custom register instruction set with native post quantum opcodes, a deterministic gas model, the bytecode container, an assembler, and a fuzzing harness. It is not the Ethereum virtual machine and it is not WebAssembly. Governed by the crypto policy in the Quantova Specs repository. Commits are authored by the owner only.
